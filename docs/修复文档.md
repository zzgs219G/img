

点击上传按钮报错 indexedDB is not defined




这个 indexedDB is not defined 错误，和之前的 vol.reset is not a function 是同一个根源：isomorphic-git 默认依赖浏览器环境（IndexedDB），但 Cloudflare Workers 没有这个 API。

🔍 错误原因

isomorphic-git 需要搭配一个文件系统（fs）才能工作。默认搭配的 LightningFS，其默认存储后端是 IndexedDB（浏览器专有）。Workers 运行在 V8 隔离环境中，没有 IndexedDB，所以会直接报错。

✅ 解决方案：用 MemoryBackend 替换 IndexedDB

官方推荐为每个请求创建一个全新的、短暂的内存文件系统，请求结束就丢弃，完全不需要持久化存储。

第一步：创建 worker/memory-backend.ts

在 worker/ 目录下新建这个文件，复制以下官方实现：

```ts
export class MemoryBackend {
  private _map = new Map<string, any>()

  saveSuperblock(superblock: any) {
    this._map.set('!root', superblock)
  }

  loadSuperblock() {
    return this._map.get('!root') || null
  }

  readFile(inode: string) {
    return this._map.get(inode) || null
  }

  writeFile(inode: string, data: any) {
    this._map.set(inode, data)
  }

  unlink(inode: string) {
    this._map.delete(inode)
  }

  async wipe() {
    this._map.clear()
  }
}
```

第二步：修改 worker/cnb.ts

把原来的 memfs 全部替换掉。核心改动如下：

```ts
// 删除这两行
// import { fs as memfs } from 'memfs'
// const vol = memfs as unknown as { reset(): void }
// vol.reset()

// 新增这两行
import LightningFS from '@isomorphic-git/lightning-fs'
import { MemoryBackend } from './memory-backend'

export async function pushToCnb(opts: CnbPushOptions): Promise<void> {
  // 每个请求创建一个全新的内存文件系统，自动隔离，无需 reset
  const fs = new LightningFS('mem', { backend: new MemoryBackend() }).promises

  const dir = '/'
  const author = { name: 'cdn-img-bot', email: 'bot@cdn-img.local' }

  await git.init({ fs, dir, defaultBranch: opts.branch })
  // ... 后续 add / commit / push 逻辑保持不变
}
```

第三步：安装依赖并清理

```bash
npm install @isomorphic-git/lightning-fs
npm uninstall memfs
```

💡 为什么这个方案对

每个 Worker 请求都 new 一个全新的 LightningFS 实例，使用内存作为存储，请求结束内存自动回收。这既符合 Worker 无状态、短生命周期的运行模型，也彻底绕开了 IndexedDB 的依赖问题。
