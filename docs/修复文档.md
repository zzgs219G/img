三、修复项 2：简化文件名

文件：src/lib/filename.ts

问题：img_YYMMDD_HHmmss_xxxx.webp 太长。

改动：去掉时分秒，随机码从 2 字节扩到 3 字节。

```ts
export function generateFilename(ext: string, type: 'img' | 'icon' = 'img'): string {
  const d = new Date()
  const p = (n: number, len = 2) => String(n).padStart(len, '0')
  const yymmdd = `${p(d.getFullYear() % 100)}${p(d.getMonth() + 1)}${p(d.getDate())}`
  const rand = Array.from(crypto.getRandomValues(new Uint8Array(3)))
    .map((b) => b.toString(16).padStart(2, '0'))
    .join('')
  return `${type}_${yymmdd}_${rand}.${ext}`
}
```

新格式：

类型 示例
普通图片 img_260920_a3f9c1.webp
图标 icon_260920_b4e2d8.webp

五、修复项 4：前端选择上传路径

文件：

· src/components/Uploader.tsx
· src/lib/filename.ts（已含 type 参数）

需求：用户上传前，可以选“普通图片”或“APP 图标”，决定存到 src/img 还是 src/icons。

改动：

Uploader.tsx 增加状态：

```ts
const [type, setType] = useState<'img' | 'icon'>('img')
```

在 DropZone 上方加一个选择器（两个按钮或 tab）：

```tsx
<div className="flex gap-2">
  <Button
    variant={type === 'img' ? 'default' : 'outline'}
    size="sm"
    onClick={() => setType('img')}
  >
    普通图片
  </Button>
  <Button
    variant={type === 'icon' ? 'default' : 'outline'}
```

生成文件名时传 type：

```ts
setCompressed({ blob: r.blob, name: generateFilename(r.ext, type) })
```

说明：Worker 侧不用改，它本来就按文件名前缀 icon_ / img_ 判断目录。

六、修复项 5：选图后布局拉长

文件：src/components/Uploader.tsx

问题：选图后，DropZone 和 Preview 同时显示，卡片被拉得很长。

方案：选图后隐藏 DropZone，只显示 Preview。重选时反向切换。

改动：

```tsx
{!file && (
  <DropZone
    disabled={uploading}
    onDrop={onDrop}
    onBrowse={() => inputRef.current?.click()}
  />
)}

{file && (
  <>
    <Preview
      url={compressed ? URL.createObjectURL(compressed.blob) : originalUrl}
      originalSize={originalSize}
      compressedSize={compressed?.blob.size ?? 0}
    />
    <Button variant="outline" size="sm" onClick={reset} disabled={uploading}>
      重选图片
    </Button>
  </>
)}
```

效果：

状态 显示内容
未选图 只有 DropZone，卡片矮
已选图 只有 Preview + 大小对比 + 重选按钮，卡片高一点但不重叠
上传中 Preview + 进度条
上传成功 Preview + ResultCard

底部按钮区也要调整：选图后，原来的“上传 / 重选”两个按钮，改成只剩“上传”一个（重选移进 Preview 区域）。
