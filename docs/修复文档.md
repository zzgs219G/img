多出了 zzgs219/cdn-img 这一段。

原因

看你的 worker/cnb.ts：

```ts
return {
  url: `${repoPage(opts.repoUrl)}${path}`,
  ...
}
```

· repoPage(opts.repoUrl) = https://cnb.cool/zzgs219/cdn-img
· path（CNB 返回的 assets.path）= /zzgs219/cdn-img/-/imgs/...

path 已经包含了仓库路径，你又在前面拼了一遍，所以重复。

修复

只保留域名，把仓库路径留给 path：

```ts
/** https://cnb.cool/zzgs219/cdn-img.git → https://cnb.cool */
function repoOrigin(repoUrl: string): string {
  const m = /^(https?:\/\/[^/]+)/.exec(repoUrl)
  if (!m) throw new Error(`无法从 CNB_REPO 解析域名: ${repoUrl}`)
  return m[1]
}
```

然后把返回改成：

```ts
return {
  url: `${repoOrigin(opts.repoUrl)}${path}`,
  name: opts.fileName,
  size: opts.content.byteLength,
}
```

最终效果

```
https://cnb.cool + /zzgs219/cdn-img/-/imgs/... = 正确 URL
```
